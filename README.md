# Kineris Labs

UK research-peptide storefront, sold strictly for laboratory Research Use Only (RUO).

Three apps in a pnpm workspace: `apps/web` (storefront), `apps/backend` (API), `apps/admin`
(admin panel), sharing types and compliance logic via `packages/shared`.

See **[docs/PROJECT_NOTES.md](docs/PROJECT_NOTES.md)** for local setup, every open decision from
the project brief and the default taken for it, and what's deliberately not built yet.
